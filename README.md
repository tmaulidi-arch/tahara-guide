# Tahara Guide — Trilingual Islamic Purification Guide

A responsive, single-page educational website explaining the steps and supplications (duas) of ghusl (ritual purification) after menstruation, presented in Arabic (RTL), French, and English.

**Live site:** https://taharajeune.netlify.app

## Features
- Fully responsive, mobile-first layout
- Right-to-left (RTL) Arabic typography alongside LTR French/English translations
- Custom SVG iconography and decorative illustrations (no external image assets)
- SEO metadata (Open Graph, meta description/keywords, JSON-LD structured data)
- Accessible design with `prefers-reduced-motion` support

## Tech stack
- HTML5 / CSS3 (custom properties, CSS Grid, Flexbox)
- No frameworks or build step — single static file, easy to deploy anywhere
- Google Fonts (Amiri for Arabic, Fraunces + Inter for Latin script)

## Deployment
Deployed via Netlify (static hosting, continuous deploy from drag-and-drop / Git).

## What this project demonstrates
- Multilingual / internationalization (i18n) considerations, including bidirectional text (RTL/LTR)
- Semantic HTML and accessible, responsive CSS without a framework
- Basic SEO fundamentals (meta tags, structured data, Search Console verification)
- Attention to visual design and typography
